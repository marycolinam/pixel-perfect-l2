# Pixel Perfect Course Card (BEM + SASS)

**Entregable del Módulo 3: Desarrollo de la Interfaz de Usuario Web.**

## Tecnologías

- HTML5
- SCSS (SASS)
- Metodología BEM

## Estructura

- `scss/` código fuente SCSS (base + components)
- `assets/css/` CSS compilado
- `assets/img/` imágenes del proyecto

## Scripts

Instalar dependencias:

```bash
npm install
```
npm run sass

## Componentes

- course-card (BEM)

    - elementos: __media, __content, __rating, __footer, etc.

        - modificador: course-card--bestseller
